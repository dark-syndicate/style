# Стили

Общие блоки промптов (композиция + стиль + рендер + цвет). Каждый промпт в `games/` начинается со строки `STYLE: styles/<файл>.md` и содержит только тематическую часть. Чтобы получить готовый промпт для генерации: текст файла стиля, пустая строка, затем всё из промпта после строки `STYLE:`.

| Файл | Стиль | Промпты |
|---|---|---|
| `style1-evolved.md` | STYLE2 evolved — исходный, полная детализация, 5 приборов на раме | `1_lunar_junk`, `2_storm_bakery`, `3_reef_rascals` |
| `style2-simplified.md` | STYLE2 slightly simplified — чуть проще формы, без грязи/ржавчины, фон из 3–4 масс, без приборов | `1_lunar_junk-simplified`, `4`–`9` |
| `style3-bold.md` | STYLE2 simplified + bold outline — ещё проще, толстая обводка, доска строго по центру | `14`, `16`, `19`, `20`, `22`, `23` |
| `style3-bold-human.md` | то же, для маскотов-людей (человеческие черты и пропорции вместо морды/клюва) | `15`, `17`, `18`, `21` |
| `style3-bold-nocenter.md` | bold outline без требования центрировать доску | `1_lunar_junk-bold`, `10`, `11` |
| `style3-bold-human-nocenter.md` | bold outline для людей, без центрирования | `12`, `13` |

## Вариации style4 (экспериментальные)

Средний уровень детализации: богаче `style2`, но не реалистичнее `style1`. Базовый цвет, до двух жёстких тонов тени и один плоский блик, фон из 4–5 крупных форм. Доска строго по центру, приборов нет. Каждый файл подходит и для животных, и для людей (в нём есть формулировка для human mascots).
