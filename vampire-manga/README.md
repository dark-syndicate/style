# Vampire Vegan × оригинальный manga-tone

Игра **Vampire Vegan** в оригинальном стиле `style4-manga-tone`, том же, что в `style-picks`. Стиль берётся прямо из `styles/style4-manga-tone.md` и ничем не изменён. Единственное, что делает сборка, как и для всех игр 6x5, — подставляет поле 6x5 в строку композиции.

```sh
bash vampire-manga/run.sh            # промпт → картинка → галерея vampire-manga/prompts-generated/index.html
bash vampire-manga/run.sh --force    # перегенерировать
```
