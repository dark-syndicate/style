# manga-dev

Рабочая папка для доводки manga-tone на трёх играх 6x5. Файлов-промптов нет: скрипт сам склеивает каждую игру с каждым стилем и отправляет готовый запрос в OpenAI.

- `styles/manga-tone-original.md` — оригинальный `style4-manga-tone`. **Не меняем.** Новые версии кладём рядом: `manga-tone-v1.md`, `manga-tone-v2.md`, …
- `styles/manga-tone-v1.md` — ваш вариант: оригинал (уже под 6x5) + чуть больше скринтона в фоне + матовый пол без отражений.
- `styles/manga-tone-v12.md` — v1 + bold-символы, чёткое разделение планов, лаконичный фон из силуэтов, точки скринтона среднего размера и только в выбранных местах (маскот и символы без точек), упрощённый реквизит, матовый пол.
- `styles/manga-tone-v13.md` — v12, но у персонажей чистые чёрные контуры тушью: никаких светлых или цветных кромок вдоль силуэта и одежды.
- `styles/manga-tone-v14.md` — v13 с серьёзными самодостаточными символами: не мультяшные, правдоподобные пропорции, без лиц и пухлости; каждый символ — один целый предмет по центру ячейки, со своим силуэтом и цветом; буквы элегантные, каждая своего цвета.
- Варианты на базе v14 (всё как в v14, плюс одна доработка символов):
  - `styles/manga-tone-v15a.md` — гравировка тушью: несколько тонких линий гравировки и чёткие гравированные кромки на металле, стекле и камне, тонкая вторичная линия внутри жирного контура.
  - `styles/manga-tone-v15b.md` — ореол: за каждым символом мягкий плоский круг его акцентного цвета с тонким тёмным кольцом, символ выглядит как отдельная драгоценная эмблема.
  - `styles/manga-tone-v15c.md` — богаче материалы: на металле две полосы отражения и яркая кромка, у стекла чёткие формы преломления и блик, у ткани и кожи складки и строчка; три ступени cel-тени только на символах.
- `games/` — `29_magnificent_mime`, `35_vampire_vegan`, `37_coupon_queen`. Только тема, без строки `STYLE:`. Наборы символов заменены на более серьёзные целые предметы (маски, канделябр, флакон духов и т.п.).
- `generated/` — картинки `<игра>--<стиль>.png` и галерея `index.html` для сравнения версий.

```sh
bash manga-dev/run.sh                              # все недостающие картинки (игры × стили)
bash manga-dev/run.sh --styles manga-tone-v1       # только одна версия стиля
bash manga-dev/run.sh --games 35                   # только Vampire Vegan
bash manga-dev/run.sh --games 35 --force           # перегенерировать
bash manga-dev/run.sh --games 35 --print           # показать собранный текст запроса
bash manga-dev/run.sh --dry-run                    # что будет сгенерировано
```
