# manga-dev

Рабочая папка для доводки manga-tone на трёх играх 6x5. Файлов-промптов нет: скрипт сам склеивает каждую игру с каждым стилем из `styles/` и отправляет готовый запрос в OpenAI.

- `styles/manga-tone-v1.md` — текущая базовая версия (бывшая v15): лаконичный фон из силуэтов, умеренные точки скринтона, матовый пол, чёрные контуры у персонажей, серьёзные самодостаточные символы с богатыми материалами. Тело маскота развёрнуто влево, к доске (вполоборота), а голова и глаза повернуты к зрителю и смотрят прямо на нас; набор символов берётся из игры, буквы A K Q J — только если они есть в описании игры. Новые итерации кладём рядом: `manga-tone-v2.md`, `manga-tone-v3.md`, …
- `games/` — `29_magnificent_mime`, `35_vampire_vegan`, `37_coupon_queen` Посейдон (`41_poseidon_beach_club`, `43`) и 20 разных игр `100`–`119`: мифология, животные, мужчины и женщины разных возрастов. `120`–`129` — серьёзные эпичные темы: вместо гэга «Signature pose», без комедии. `130`–`139` — стройные красивые воительницы, на доске нарисована фича (expanding wild с Фенриром, sticky, walking, colossal, hold and win и т.д.). `140`–`149` — серьёзная скандинавская серия: у всех одна и та же воительница-образ по референсу (рогатый шлем, меховая накидка, кожаная броня с открытым животом, короткая юбка с мехом, высокие сапоги, рваный плащ), меняются волосы, шлем, мех и цвет плаща. `149_bifrost_guardian-v2` — та же игра с очень подробным описанием героини по референсу (поза, мимика и взгляд, какие части тела открыты). `149_bifrost_guardian-v3` — то же, но с очень подробным положением головы и взглядом исподлобья; цвета одежды (серебряный шлем, белый лисий мех, синий плащ, платиновые волосы) и белый конь — как в первой версии. У новых игр 4 высших и 5 низших символов, без A K Q J. Только тема, без строки `STYLE:`.
- `generated/` — картинки `<игра>--<стиль>.png` и галерея `index.html`.
- `archive/` — прежние стили (оригинальный manga-tone, старая v1, v12–v14) и старые картинки. Скрипт их не использует.

```sh
bash manga-dev/run.sh                              # все недостающие картинки (игры × стили)
bash manga-dev/run.sh --styles manga-tone-v1       # только одна версия стиля
bash manga-dev/run.sh --games 35                   # только Vampire Vegan
bash manga-dev/run.sh --games 35 --force           # перегенерировать
bash manga-dev/run.sh --games 35 --again 10        # ещё 10 картинок, старые не трогаются (-take2, -take3, …)
bash manga-dev/run.sh --games 35 --print           # показать собранный текст запроса
bash manga-dev/run.sh --dry-run                    # что будет сгенерировано
```

Галерея:

```sh
bash manga-dev/view.sh      # откроет http://localhost:8765/ — страница сама находит все картинки в generated/
                            # и каждые 10 секунд подхватывает новые, ничего пересобирать не нужно
```

Если открыть `generated/index.html` двойным кликом, браузер не даст странице прочитать папку, и она покажет список на момент последней сборки.
