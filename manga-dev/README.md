# manga-dev

Рабочая папка для доводки manga-tone на трёх играх 6x5. Файлов-промптов нет: скрипт сам склеивает каждую игру с каждым стилем и отправляет готовый запрос в OpenAI.

- `styles/manga-tone-original.md` — оригинальный `style4-manga-tone`. **Не меняем.** Новые версии кладём рядом: `manga-tone-v1.md`, `manga-tone-v2.md`, …
- `styles/manga-tone-v1.md` — ваш вариант: оригинал (уже под 6x5) + чуть больше скринтона в фоне + матовый пол без отражений.
- `styles/manga-tone-v2.md` — v1, в которой немного улучшены только символы на доске: чуть крупнее (~80% ячейки), чище силуэты, контур чуть толще, плоский блик, буквы A K Q J чуть массивнее и разных цветов, спецсимвол с небольшой вспышкой. Всё остальное как в v1.
- `styles/manga-tone-v3.md` — v2 + чёткое разделение планов (фон тоньше контуром, ниже контраст, приглушённее; рама, маскот и логотип с жирным контуром, полным цветом и светлым кантом по силуэту) + символы с чертами bold: ~85% ячейки, пухлые, ракурс 3/4, толстый контур со светлым внутренним кантом, сочный блик, выпуклые буквы разных цветов.
- `styles/manga-tone-v4.md` — v3 + точки скринтона не только на фоне, но и на теневых сторонах объектов (реквизит, тележка, декор, тени рамы; не на лицах и не на символах) + чуть проще объекты переднего плана, кроме маскота и доски.
- `styles/manga-tone-v5.md` — v4, но задний план собран в основном из простых силуэтов: здания, башни, деревья, холмы — плоские формы в тонах фона с тонким мягким контуром, почти без деталей внутри (только редкие тёплые окошки), с точками скринтона; ближние силуэты чуть темнее и чётче, дальние светлее и проще.
- `styles/manga-tone-v6.md` — v5 + лаконичный фон: всего 3–4 крупные массы силуэтов и спокойное открытое небо, без нагромождения, мелочей и повторяющихся элементов, много воздуха между формами.
- `games/` — `29_magnificent_mime`, `35_vampire_vegan`, `37_coupon_queen`. Только тема, без строки `STYLE:`.
- `generated/` — картинки `<игра>--<стиль>.png` и галерея `index.html` для сравнения версий.

```sh
bash manga-dev/run.sh                              # все недостающие картинки (игры × стили)
bash manga-dev/run.sh --styles manga-tone-v1       # только одна версия стиля
bash manga-dev/run.sh --games 35                   # только Vampire Vegan
bash manga-dev/run.sh --games 35 --force           # перегенерировать
bash manga-dev/run.sh --games 35 --print           # показать собранный текст запроса
bash manga-dev/run.sh --dry-run                    # что будет сгенерировано
```
