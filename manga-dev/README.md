# manga-dev

Рабочая папка для доводки manga-tone на трёх играх 6x5. Файлов-промптов нет: скрипт сам склеивает каждую игру с каждым стилем и отправляет готовый запрос в OpenAI.

- `styles/manga-tone-original.md` — оригинальный `style4-manga-tone`. **Не меняем.** Новые версии кладём рядом: `manga-tone-v1.md`, `manga-tone-v2.md`, …
- `styles/manga-tone-v1.md` — ваш вариант: оригинал (уже под 6x5) + чуть больше скринтона в фоне + матовый пол без отражений.
- `styles/manga-tone-v12.md` — v1 + bold-символы, чёткое разделение планов, лаконичный фон из силуэтов, точки скринтона среднего размера и только в выбранных местах (маскот и символы без точек), упрощённый реквизит, матовый пол.
- Символы на базе v12 (всё остальное как в v12): каждый символ самобытен, со своим силуэтом и характером, в манга-cel языке сцены, лаконичный, но чуть богаче фона. Цвет зависит от механики:
  - `styles/manga-tone-v13-lines.md` — для игр на линиях: у всех символов, старших и младших, один общий акцентный цвет (кант или деталь), база и силуэт у каждого свои.
  - `styles/manga-tone-v13-cluster.md` — для кластерных игр: у каждого типа символа свой ярко отличающийся акцентный цвет по всему кругу, у каждой буквы тоже свой.
- `styles/manga-tone-v14-lines.md`, `styles/manga-tone-v14-cluster.md` — то же, что v13, но символы детальнее: 4–5 деталей на символ (складка, шов, трещина, прожилка, кант, полоса отражения, намёк на текстуру), по-прежнему чисто и без перегруза.
- Свободные варианты символов на базе v12 (общее: каждый символ со своим силуэтом и акцентным цветом, манга-cel, 4–5 деталей, спецсимвол со вспышкой):
  - `styles/manga-tone-v15a.md` — «манга-наклейка»: белая вырубная обводка с тонкой тушевой линией и маленькой тенью, символы отрываются от тёмной доски.
  - `styles/manga-tone-v15b.md` — «тушь и золото»: кистевой контур, плоские насыщенные цвета, отдельные края и орнаменты золотом (плоская охра с одной светлой кромкой), буквы-тушь с золотой окантовкой.
  - `styles/manga-tone-v15c.md` — «символы-персонажи»: у тематических символов маленькие глазки и эмоции в духе маскота (самодовольный, испуганный, сонный), буквы с маленькой тематической деталью.
- `games/` — `29_magnificent_mime`, `35_vampire_vegan`, `37_coupon_queen`. Только тема, без строки `STYLE:`.
- `generated/` — картинки `<игра>--<стиль>.png` и галерея `index.html` для сравнения версий.

```sh
bash manga-dev/run.sh                              # все недостающие картинки (игры × стили)
bash manga-dev/run.sh --styles manga-tone-v1       # только одна версия стиля
bash manga-dev/run.sh --games 35                   # только Vampire Vegan
bash manga-dev/run.sh --games 35 --force           # перегенерировать
bash manga-dev/run.sh --games 35 --print           # показать собранный текст запроса
bash manga-dev/run.sh --dry-run                    # что будет сгенерировано
```
