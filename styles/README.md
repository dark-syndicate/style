# Стили

Общие блоки промптов (композиция + стиль + рендер + цвет). Каждый промпт в `games/` начинается со строки `STYLE: styles/<файл>.md` и содержит только тематическую часть. Чтобы получить готовый промпт для генерации: текст файла стиля, пустая строка, затем всё из промпта после строки `STYLE:`.

| Файл | Стиль | Игры |
|---|---|---|
| `style1-evolved.md` | исходный, полная детализация, 5 приборов на раме | `1`–`3` |
| `style2-simplified.md` | чуть проще формы, без грязи и ржавчины, фон из 3–4 масс, без приборов | `1_lunar_junk-simplified`, `4`–`9` |
| `style3-bold.md` | ещё проще, толстая обводка, доска строго по центру | `1_lunar_junk-bold`, `10`–`23` |
| `style4-faceted-geo.md` | средняя детализация; фон и предметы из плоских граней, персонаж округлый | `27` |
| `style4-manga-tone.md` | средняя детализация; скринтон манги в фоне, цветной передний план | `24`–`26`, `28`–`38` |

Остальные стили (варианты bold для людей и без центрирования, 38 вариаций style4, гибриды) удалены. Их тексты остаются в истории git и в уже собранных промптах `style-test/` и `style-picks/`.
