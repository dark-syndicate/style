# Manga-tone lab: улучшаем символы

Оригинал `style4-manga-tone` и 3 модификации, которые меняют только символы на поле, на 4 новых играх 6x5. Всего 16 промптов.

## Стили (`styles/`)

| Файл | Что меняется |
|---|---|
| `manga-tone-original.md` | `styles/style4-manga-tone.md` с двумя общими правками ниже, эталон для сравнения |
| `manga-tone-bold-icons.md` | крупные пухлые символы в ракурсе 3/4, толстый контур + светлый внутренний кант, сочный блик, выпуклые буквы; фон спокойный и простой, как у original; передний план чуть проще |
| `manga-tone-ink-icons.md` | символы той же манга-линией, что и маскот, динамичный ракурс, импакт-вспышки за дорогими символами, буквы как манга-импакт |
| `manga-tone-premium-icons.md` | богатые материалы в cel-подаче: металл, грани камней, глянец, контровой кант, плоская тень, буквы с фаской и эмалевой вставкой |

Общее для всех трёх модификаций:
- символ занимает ~85% ячейки;
- дорогие символы богаче букв;
- A K Q J каждая своего цвета (A красная, K синяя, Q зелёная, J фиолетовая) и легко читаются;
- спецсимвол крупнее и со вспышкой;
- на символах нет скринтона.

Во всех четырёх стилях, включая original, добавлены две правки:
- чуть больше манги в фоне: немного точек скринтона на части стен и неба, тонкий линейный тон в некоторых тенях, большая часть фона остаётся чистым цветом;
- матовый пол: никаких отражений и мокрого блеска, земля залита плоским тоном с точками.

## Игры (`games/`)

| Игра | Маскот и гэг |
|---|---|
| `34_penguin_post` | пингвин-почтальон на коньках, из лопнувшей сумки улетает шлейф писем |
| `35_vampire_vegan` | вампир пьёт томатный сок, а летучая мышь ворует глотки с соломинки |
| `36_knight_shift` | рыцарь-охранник музея светит фонариком, а доспех-экспонат ворует его обед |
| `37_coupon_queen` | королева скидок с ножницами-скипетром, из кармана тянется лента купонов |

## Запуск

```sh
bash manga-lab/run.sh                 # собрать 16 промптов, сгенерировать картинки, обновить галерею
bash manga-lab/run.sh --only 34_      # только одна игра (аргументы передаются генератору)
```

Картинки и галерея: `manga-lab/prompts-generated/index.html`.
