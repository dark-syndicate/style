# manga-dev

Рабочая папка для доводки manga-tone на трёх играх 6x5. Файлов-промптов нет: скрипт сам склеивает каждую игру с каждым стилем и отправляет готовый запрос в OpenAI.

- `styles/manga-tone-original.md` — оригинальный `style4-manga-tone`. **Не меняем.** Новые версии кладём рядом: `manga-tone-v1.md`, `manga-tone-v2.md`, …
- `styles/manga-tone-v2.md` — оригинал + чуть более плоский задний фон (плоская заливка, одна тень, меньше бликов и мелочей) + матовый пол без отражений.
- `styles/manga-tone-v3.md` — v2 + самый дальний фон в виде простых плоских силуэтов почти без деталей + чуть проще объекты переднего плана (рама, костюм, транспорт, предметы).
- `styles/manga-tone-v4.md` — v3, но дальний фон по референсу: силуэты в цвете неба на пару тонов темнее, тонкий мягкий контур, внутри почти ничего, всё залито мягкими точками скринтона, только несколько тёплых окошек; большой простой диск луны/солнца и мелкие тёмные силуэты птиц или летучих мышей.
- `styles/manga-tone-v5.md` — v4, но площе в целом: одна жёсткая тень вместо двух, максимум маленький плоский блик, форма держится на контуре и плоском цвете, без объёмной лепки, градиентов и пластикового блеска (и у маскота, и у рамы, и у символов).
- `styles/manga-tone-v6.md` — v5 + выразительные символы как в прежнем bold-icons: крупные (~85% ячейки), пухлые, ракурс 3/4, толстый контур со светлым кантом, буквы A K Q J разных цветов, спецсимвол крупнее со вспышкой; но одна тень и сочный плоский блик, чтобы не выбиваться из плоской подачи.
- `styles/manga-tone-v7.md` — v6 + мягкий вертикальный градиент только в небе и дальних силуэтах (вверху темнее, у горизонта светлее, дальние слои чуть светлее) для контраста и глубины; передний план остаётся плоским.
- `styles/manga-tone-v8.md` — v7 с сильным градиентом: наверху очень тёмное небо, у горизонта яркая светящаяся полоса, дальние слои заметно светлее и туманнее; передний план по-прежнему плоский.
- `styles/manga-tone-v9.md` — v8, но в дальнем фоне много переходов от тёмного к обычному тону: небо сверху темнее и плавно уходит в свой обычный цвет, и у каждого дальнего силуэта (башня, дом, холм) своя плавная растяжка от тёмного у основания и краёв к обычному тону выше.
- `styles/manga-tone-v10.md` — v9 + чуть сильнее точки скринтона в фоне, ярко выраженный контраст фона (глубокие почти чёрные тени против светлых зон и луны), более комиксная подача: жирные чёрные контуры с перепадом толщины везде, чёрные пятна теней, немного коротких штрихов в тенях.
- `games/` — `29_magnificent_mime`, `35_vampire_vegan`, `37_coupon_queen`. Только тема, без строки `STYLE:`.
- `generated/` — картинки `<игра>--<стиль>.png` и галерея `index.html` для сравнения версий.

```sh
bash manga-dev/run.sh                              # все недостающие картинки (игры × стили)
bash manga-dev/run.sh --styles manga-tone-v1       # только одна версия стиля
bash manga-dev/run.sh --games 35                   # только Vampire Vegan
bash manga-dev/run.sh --games 35 --force           # перегенерировать
bash manga-dev/run.sh --games 35 --print           # показать собранный текст запроса
bash manga-dev/run.sh --dry-run                    # что будет сгенерировано
```
